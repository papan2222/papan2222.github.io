There would be no society if living together depended upon understanding each other.

お互いを理解することが共同生活の条件なら、社会は存在しないだろう。

エリック・ホッファー ／ Eric Hoffer

ENGLISH TIP

  • There would be no ... if ...：もし〜なら…は存在しない（仮定法）
  • depend upon：〜に依存する
  • each other：互いに

1902–1983 アメリカの社会思想家。港湾労働者として働きながら、大衆運動や人間心理について著述した。
