If a man writes a book, let him set down only what he knows.

人が本を書くなら、自分が知っていることだけを書け。

ヨハン・ヴォルフガング・フォン・ゲーテ ／ Goethe

ENGLISH TIP

  • let him do：彼に〜させよ、彼は〜すべきだ
  • set down：書き記す
  • what he knows：自分が知っていること

1749–1832 ドイツの詩人、作家、劇作家。『ファウスト』などの文学作品を残し、自然科学にも取り組んだ。
