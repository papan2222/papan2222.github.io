Using the same words does not ensure understanding; shared experience is required.

同じ言葉を使っても理解は保証されない。共通の体験が必要だ。

フリードリヒ・ニーチェ ／ Nietzsche

ENGLISH TIP

  • ensure：確実にする、保証する
  • shared experience：共有された経験
  • be required：必要とされる（受動態）

1844–1900 ドイツの哲学者。道徳や価値観を問い直し、『ツァラトゥストラはこう語った』などを著した。
