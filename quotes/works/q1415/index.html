Know thyself? If I knew myself I would run away.

「汝自身を知れ」？ 自分を知ったら私は逃げ出すだろう。

ヨハン・ヴォルフガング・フォン・ゲーテ ／ Goethe

ENGLISH TIP

  • thyself：yourself の古風な形
  • If I knew ..., I would ...：もし〜を知っていたら…するだろう（仮定法過去）
  • run away：逃げ出す

1749–1832 ドイツの詩人、作家、劇作家。『ファウスト』などの文学作品を残し、自然科学にも取り組んだ。
