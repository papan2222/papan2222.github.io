One should die proudly when it is no longer possible to live proudly.

誇りを持って生きられぬなら、誇りを持って死ぬべきだ。

フリードリヒ・ニーチェ ／ Nietzsche

ENGLISH TIP

  • proudly：誇りを持って
  • no longer：もはや〜ない
  • it is possible to do：〜することが可能である（原文は死に関する哲学的主張であり、行動を勧めるものではない）

1844–1900 ドイツの哲学者。道徳や価値観を問い直し、『ツァラトゥストラはこう語った』などを著した。
