Win as if you were used to it, lose as if you enjoyed it for a change.

勝つときは慣れた顔で、負けるときは気分転換のように楽しめ。

ラルフ・ウォルドー・エマソン ／ R. W. Emerson

ENGLISH TIP

  • as if：まるで〜であるかのように
  • be used to it：それに慣れている
  • for a change：いつもと違って、たまには

1803–1882 アメリカの思想家、詩人、随筆家。超絶主義を代表し、自然や自己信頼について論じた。
