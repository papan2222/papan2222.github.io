To buy books would be a good thing if we also could buy the time to read them.

本を買うのはよいことだ。もし読む時間まで一緒に買えるのなら。

アルトゥル・ショーペンハウアー ／ Schopenhauer

ENGLISH TIP

  • would be ... if ... could：もし〜できるなら…だろう（仮定法過去）
  • the time to read them：それらを読む時間（them は books を指す）

1788–1860 ドイツの哲学者。『意志と表象としての世界』を著し、欲望や苦悩、芸術について論じた。
