We hear only those questions we can answer.

人は答えられる問いしか聞こえない。

フリードリヒ・ニーチェ ／ Nietzsche

ENGLISH TIP

  • those questions：それらの疑問
  • we can answer：私たちが答えられる（目的格の関係代名詞の省略）

1844–1900 ドイツの哲学者。道徳や価値観を問い直し、『ツァラトゥストラはこう語った』などを著した。
