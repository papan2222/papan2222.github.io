When one has not had a good father, one must create one.

よき父を持たなかった者は、自らそれを作らねばならない。

フリードリヒ・ニーチェ ／ Nietzsche

ENGLISH TIP

  • one：一般の人を指す代名詞
  • has not had：これまで持ったことがない（現在完了）
  • create one：一人の父親を創り出す（理想の父親像を作るという含意）

1844–1900 ドイツの哲学者。道徳や価値観を問い直し、『ツァラトゥストラはこう語った』などを著した。
