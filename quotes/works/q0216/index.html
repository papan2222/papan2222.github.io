The main difference between a cat and a lie is that a cat only has nine lives.

猫と嘘の主な違いは、猫は命が九つしかないが、嘘はそうではないことだ。

マーク・トウェイン ／ Mark Twain

ENGLISH TIP

  • difference between A and B：AとBの違い
  • lie：うそ（名詞）
  • nine lives：猫には九つの命があるという英語圏の言い伝え

1835–1910 アメリカの作家、ユーモリスト。『トム・ソーヤーの冒険』などを著し、社会を風刺した。
