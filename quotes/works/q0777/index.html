It is a very sad thing that nowadays there is so little useless information.

今では役に立たない情報がほとんどないことは、とても悲しいことだ。

オスカー・ワイルド ／ Oscar Wilde

  • nowadays：近頃
  • so little：非常に少ない
  • useless information：役に立たない情報
