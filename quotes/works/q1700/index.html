Wealth is like sea-water; the more we drink, the thirstier we become; and the same is true of fame.

富は海水のようなものだ。飲めば飲むほど渇き、名声もまた同じだ。

アルトゥル・ショーペンハウアー ／ Schopenhauer

ENGLISH TIP

  • sea-water：海水（seawater とも書く）
  • the more ... , the thirstier ...：〜すればするほど、ますます喉が渇く（比例比較）
  • the same is true of：〜についても同じことが言える

1788–1860 ドイツの哲学者。『意志と表象としての世界』を著し、欲望や苦悩、芸術について論じた。
