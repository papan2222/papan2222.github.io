たけのこ掘り

🐼　たけのこ掘るの、楽しみだねぇ

👦　もし見つからなかったら？

🐼　君と探した思い出だけでも、十分な収穫さ

🐼 I’m excited to dig up bamboo shoots!

👦 What if we don’t find any?

🐼 Then the memory of our bamboo shoot hunt is harvest enough.

英語学習ポイント

  • dig up /dɪɡ ʌp/：掘り出す。
  • harvest /ˈhɑrvəst/：収穫。ここでは思い出を収穫にたとえている。
  • What if ～?：もし～だったらどうする？
