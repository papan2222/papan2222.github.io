雨を駆ける

きょうは土曜！カフェのモーニングサービスのため走る！ぼくたちヒーローみたい！

Today is Saturday! We're running for the cafe's morning service! We're like heroes!

英語学習ポイント

  • hero /ˈhɪroʊ/：英雄。複数形は heroes。
  • run for /rʌn fɔr/：～を求めて走る。
  • morning service は日本の喫茶店の朝食サービスを指す文脈。英語では breakfast special なども使える。
