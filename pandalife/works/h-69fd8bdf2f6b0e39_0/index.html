帰り道

🐼　ひろし、少し急ごう。晩飯が待ってる

👦　もし君がいなくなっちゃうなら、一緒にいた時間を覚えていたい。だから、ゆっくり。

🐼　Hiroshi, a little faster. Dinner’s waiting.

👦　If you’re going back someday, I want to remember this. So let’s walk slow.

英語学習ポイント

  • someday /ˈsʌmdeɪ/：いつか。
  • Dinner’s waiting.：夕食が待っている、という擬人化。
  • walk slow：くだけた表現。標準的には walk slowly。
