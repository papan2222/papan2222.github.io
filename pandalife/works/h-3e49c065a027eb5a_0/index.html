風呂

🐼 銭湯、幸せだ..

🐷 僕らぬいぐるみだよ。これ、丸洗いだよ。

🐼 干される覚悟もできてる。いろんな意味でな

🐼 This is a Japanese bath. Love it…

🐷 We’re plushies… that’s laundry.

🐼 Yeah, well… I’m ready to be hung up—on the line and in life.

英語学習ポイント

  • plushie /ˈplʌʃi/：ぬいぐるみ（親しみのある口語）。
  • laundry /ˈlɔndri/：洗濯物、洗濯。
  • hang up /hæŋ ʌp/：つるす。hung up は過去分詞形。on the line は物干し綱に、という意味。
